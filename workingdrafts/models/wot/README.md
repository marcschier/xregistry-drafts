# WoT Registry Service - Version 1.0-rc4

<!-- words: WoT readme -->

See the [WoT Registry specification](spec.md), its [model](model.json), its
[decision record](decisions.md), and the [samples](samples/README.md).

All WoT document kinds share `thinggroups` / `things`. The required `kind`
metadata distinguishes `ThingDescription`, `ThingModel`, and provisional
`ThingProjection` documents and supports kind-filtered discovery and access.
